# 已有 GPT 邻居决策的离线审计

`mre_neighbor_audit.py` 仅依赖 Python 3.8+ 标准库，不导入训练模块，不加载 BERT/CUDA，不调用 API。它读取每次运行自己的 `data/manifest.json`、有标签训练/测试文件及 `neighbor_queries.jsonl`，验证划分文件的 SHA256、样本 ID 与标签范围后统计。不会修改原训练数据、配置、模型或指标。

```bash
python mre_neighbor_audit.py --run-dir outputs/loop_mre_fewrel_gpt35_v2_seed3_20260918_090257_133428
```

在 `--run-dir` 后可填写多个输出目录（空格分隔）。默认新建 `outputs/neighbor_audit_时间戳/`，生成每个运行的 JSON 和适合粘贴到腾讯在线表格的 `summary.txt`。可用 `--output-dir 新目录` 指定位置，已有目录不覆盖。no-LLM 运行通常没有查询日志，不能用于审计 GPT 判断。

## 怎样解释统计

| 字段 | 定义 |
| --- | --- |
| 决策数 | 查询日志行数；不是独立样本数、API 请求数或全部训练正对数 |
| 不同 Query 数 | 查询样本 ID 去重后的数量 |
| 候选含同类 | 两个候选至少一个与 Query 标签相同；限定这两个候选时的选择准确率上限 |
| 两项都异类 | 两个候选都不是 Query 真实类别；强制二选一必产生异类正对 |
| 有唯一正确项时选对 | 恰好一个候选同类时的选择准确率，随机期望为 50% |
| 所选同类 | 最终选择与 Query 标签相同的比例 |
| 同候选随机期望 | 每条决策正确候选数量 / 2，再在同一范围平均；不是另跑随机实验 |
| 比随机高 | 所选同类率减上述随机期望，单位百分点；不是最终聚类分数变化 |

按查询的 Base/Novel 分组。JSON 比例为 0–1，文本摘要为百分数。空分母为 null/n/a，不伪造 0%。

三个统计范围：全部决策；排除 API 回退；进一步排除任一候选是 Query 自身或同文本的决策。第三种检查排除平凡匹配后的表现，但子集更难，不能将其绝对正确率与全集直接比较来宣称改善。

同文本沿用数据审计的 casefold 文本定义，包含同一 ID；不是 token 级或语义级检测。冲突标签保留，不自动清洗。JSON 还提供每关系指标、错边 Base/Novel 去向和纯 LLM 错误关系对计数。

旧日志没有 epoch/refresh 字段，无法可靠恢复每轮指标；同一 Query 不同刷新期间可以重复计数，刷新内缓存重用没有逐次写日志。这里只测已查询边，无法恢复完整 top-k 纯度、所有未查询边或实际累计梯度影响。

## 研究边界

真实标签只用于事后诊断，不能接入训练，不能按测试真值删除邻居，也不能在正式 novel 测试标签上选阈值。新方法校准应在 base 内部构造独立开发协议。报告为描述性诊断，不检验显著性、不自动断言下降原因。

先看候选覆盖，再看恰一正确项时的选择准确率，再看同候选随机期望差。覆盖低检查检索；判断差检查 GPT 判别；边质量较好却无提升，再检查采样多样性与损失传播。
